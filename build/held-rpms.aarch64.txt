# The OpenSSL FIPS provider below carries the module that FIPS 140-3
# certificate #4857 covers. The certificate names the module's version,
# 3.0.7-395c1a240fbfffd8, which "openssl list -providers" prints; the
# package's own version, 3.0.7-8.el9, is Red Hat's repackaging of it.
# https://csrc.nist.gov/projects/cryptographic-module-validation-program/certificate/4857
#
# Certificate #4857 lists no aarch64 platform (it was tested on Intel Xeon,
# IBM z16 and IBM POWER10): on aarch64 this is the validated module version,
# but not a validated configuration.
#
# Red Hat's repository index now lists only 3.0.7-11.el9_8, whose module,
# 3.0.7-cda111b5812c30d4, is not yet certified. RHSA-2026:27744 says that
# build fixes CVE-2026-31790 (moderate); this one does not. The held files
# are fetched by address and checked against their checksums. Nothing
# promises that Red Hat keeps files its index no longer lists; if they go,
# every image build stops.
#
